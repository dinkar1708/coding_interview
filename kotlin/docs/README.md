# Coding Interview Documentation

Comprehensive guides and references for technical interview preparation.

## 📂 Directory Structure

### 🔤 kotlin-basics/
Fundamental Kotlin concepts and data structures:
- **arrays-in-kotlin.md** - Array operations, two pointers, common patterns
- **strings-in-kotlin.md** - String manipulation, StringBuilder, regex
- **maps-in-kotlin.md** - HashMap, frequency counting, common patterns
- **2d-arrays-in-kotlin.md** - Matrix operations, traversals, flood fill
- **number-iteration-in-kotlin.md** - Primes, GCD, factorials, digit manipulation
- **intarray-reference-behavior.md** - Reference vs copy, common pitfalls
- **when-to-use-what.md** - Data structure selection guide

### 📊 algorithm-theory/
Core algorithmic concepts and analysis:
- **algorithms_complexity_cheatsheet.md** - Big O reference for all algorithms
- **dp_patterns.md** - Complete DP guide (Types A-G: Fibonacci, Knapsack, LCS, etc.)
- **sorting_searching_algorithms.md** - All sorting/searching algorithms with code

### 🌳 data-structures/
Deep dives into specific data structures:
- **linked_list_reversal.md** - All reversal techniques and patterns
- **tree_interview_questions.md** - 20+ tree problems with solutions

### 🎯 interview-prep/
Interview strategies and preparation:
- **interview_patterns.md** - 15 problem-solving patterns (Two Pointers, Sliding Window, etc.)
- **special_notes.md** - Interview tips, gotchas, communication strategies
- **todo.md** - Study schedule, problem checklist, progress tracker

### 🛠️ techniques/
Advanced algorithmic techniques:
- **hashmap-patterns.md** - Frequency counting, two sum variations
- **sliding-window-dp-optimization.md** - Window patterns, Kadane's algorithm
- **prefix-sum-technique.md** - Prefix sum applications
